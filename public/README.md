# Workshop Week 2 — Business Page (Flexbox + Responsive)

> **รายวิชา:** 3093201 การเขียนโปรแกรมสำหรับธุรกิจออนไลน์
> **เวลา:** 90 นาที (Pair Programming) + 20 นาที Show & Tell
> **ผู้สอน:** ผศ.ปพนพัชญ์ ธนาเศรษฐ์วัฒน

---

## 🎯 โจทย์

สร้างหน้าเว็บโปรไฟล์สำหรับ **ธุรกิจในจังหวัดจันทบุรี** 1 ธุรกิจที่คุณเลือก เช่น
- ร้านขายผลไม้ • รีสอร์ท • ร้านของฝาก • ร้านอาหาร • ร้านเครื่องประดับ • ฯลฯ

หน้าเว็บต้องใช้งานได้ทั้งบน Desktop และ Mobile โดยใช้ **CSS Flexbox + Media Query เท่านั้น**

    ├── hero.svg

    └── product-4.svg

## 🚀 ขั้นตอนเริ่มต้น (5 นาทีแรก)

1. **Extract** ไฟล์ ZIP ลงในโฟลเดอร์ของกลุ่ม
2. **เปิดโฟลเดอร์ใน VS Code** → `File > Open Folder`
3. **เปิด `index.html` ใน browser**
   - คลิกขวาที่ไฟล์ใน VS Code → `Reveal in File Explorer` → ดับเบิ้ลคลิกเปิดด้วย Chrome
   - หรือใช้ extension **Live Server** (ถ้าติดตั้งไว้)
4. **เปิด DevTools** (F12) → คลิก **Device Toolbar** (📱 มุมซ้ายบน) เพื่อดูบน mobile
5. **ตกลงกันในคู่** ว่าจะทำธุรกิจอะไร แล้วเริ่มกัน

## ✏️ สิ่งที่ต้องทำ

### A. ปรับเนื้อหาให้ตรงกับธุรกิจของคุณ (ใน `index.html`)

| เกณฑ์ | คะแนน | รายละเอียด |

## 💡 เคล็ดลับ Pair Programming

- **Driver** = คนพิมพ์ • **Navigator** = คนคิด/อ่านโค้ด/ชี้แนวทาง
- **สลับบทบาททุก 15 นาที** (อาจารย์จะเปิด timer)
- Navigator **ห้ามแย่งคีย์บอร์ด** — พูดได้ พิมพ์ไม่ได้
- ไม่เข้าใจ → ถามเพื่อนคู่ก่อน → ยังตัน → เปิด `hints.md` → ยังตัน → เรียกอาจารย์

## 🎤 Show & Tell (20 นาที สุดท้าย)

อาจารย์จะสุ่ม 2-3 คู่ ขึ้นนำเสนอ คู่ละ 5 นาที โดยเล่า:
1. เลือกธุรกิจอะไร เพราะอะไร?
2. ใช้ Flexbox properties อะไรบ้าง (อย่างน้อย 3 ตัว)
3. ปัญหาที่เจอ + วิธีแก้
4. **Demo Responsive** — ลากขนาดหน้าจอให้ทั้งห้องดู
